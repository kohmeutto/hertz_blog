## 1. 얼마나 갈 것인가 — 감쇠 인자

### 1.1 왜 걸음을 줄여야 하는가

$\tilde J$ 대신 $S$ 로 방향을 잡으므로, 그 방향은 정확하지 않습니다.
`60_유도_상한.md` 1.3 에서 본 대로입니다.

$$\delta\mathbf u_{\text{실제}} - \delta\mathbf u_{\text{정확}} = S^{-1}A\,\delta\mathbf u_{\text{정확}}$$

$$\text{틀린 방향으로 끝까지 가면 넘어갑니다}$$

그래서 $\sigma$ 를 곱해 줄입니다.  **얼마로 줄일지를 구하는 것이 이 절입니다.**

### 1.2 무엇을 가장 작게 만들 것인가

한 걸음 간 뒤의 잔차를 봅니다.

$$\delta\mathbf u_\sigma = \sigma\,\delta\mathbf u_{\text{실제}}, \qquad
\text{한 걸음 뒤 잔차} \approx \tilde{\mathbf F} + \tilde J\,\delta\mathbf u_\sigma$$

이것이 지금 잔차에 견주어 얼마나 줄었는지가 관심사입니다.

$$\varsigma(\sigma) = \frac{\lVert \tilde{\mathbf F} + \tilde J\,\delta\mathbf u_\sigma\rVert}{\lVert\tilde{\mathbf F}\rVert}$$

$$\text{이 값을 가장 작게 만드는 } \sigma \text{ 를 찾습니다}$$

### 1.3 잔차를 정리한다

$\delta\mathbf u_{\text{실제}} = S^{-1}(-\tilde{\mathbf F})$ 를 넣습니다.

$$\tilde J\,\delta\mathbf u_\sigma = \sigma\,\tilde J S^{-1}(-\tilde{\mathbf F})
= -\sigma(S + A)S^{-1}\tilde{\mathbf F}$$

괄호를 풉니다.

$$(S + A)S^{-1} = SS^{-1} + AS^{-1} = I + AS^{-1}$$

$$\therefore\ \tilde J\,\delta\mathbf u_\sigma = -\sigma\bigl(I + AS^{-1}\bigr)\tilde{\mathbf F}$$

$\tilde{\mathbf F}$ 를 더합니다.

$$\tilde{\mathbf F} + \tilde J\,\delta\mathbf u_\sigma
= \tilde{\mathbf F} - \sigma\tilde{\mathbf F} - \sigma AS^{-1}\tilde{\mathbf F}$$

$$\boxed{\ \tilde{\mathbf F} + \tilde J\,\delta\mathbf u_\sigma
= \bigl[(1-\sigma)I - \sigma AS^{-1}\bigr]\tilde{\mathbf F}\ }$$

### 1.4 어느 자로 재는가

해는 $S$ 로 잰 길이를 씁니다.  그러면 잔차는 그 짝인 $S^{-1}$ 로 재야 합니다.

$$\lVert\mathbf x\rVert_S = \sqrt{\mathbf x^{*}S\mathbf x},
\qquad \lVert\mathbf F\rVert_{S^{-1}} = \sqrt{\mathbf F^{*}S^{-1}\mathbf F}$$

**왜 짝을 맞춰야 하는가.**  $\rho_{\mathrm{int}}$ 를 $S$ 로 잰 자로 얻었기 때문입니다.
다른 자로 재면 그 값을 쓸 수 없습니다.

### 1.5 자를 보통 자로 바꾼다

$G = S^{-1/2}$ 로 두면 $S^{-1}$ 로 재는 것이 보통 길이가 됩니다.

$$\lVert\mathbf F\rVert_{S^{-1}} = \sqrt{(G\mathbf F)^{*}(G\mathbf F)} = \lVert G\mathbf F\rVert_2$$

1.3 의 결과 양쪽에 $G$ 를 곱합니다.  가운데를 정리하면

$$G\,AS^{-1} = S^{-1/2}A S^{-1}
= \underbrace{S^{-1/2}A S^{-1/2}}_{\tilde B}\cdot S^{-1/2} = \tilde B\,G$$

$$\therefore\ G\bigl[(1-\sigma)I - \sigma AS^{-1}\bigr]
= \bigl[(1-\sigma)I - \sigma\tilde B\bigr]G$$

그러면 축소율이 이 꼴로 잡힙니다.

$$\varsigma(\sigma) = \bigl\lVert (1-\sigma)I - \sigma\tilde B \bigr\rVert_2$$

### 1.6 $\tilde B$ 의 고윳값을 안다

$\tilde B$ 도 반대칭입니다.

$$\tilde B^{\mathsf T} = S^{-1/2}A^{\mathsf T}S^{-1/2} = -\tilde B$$

`60_유도_상한.md` 3.2 에서 본 대로 반대칭 행렬의 고윳값은 순허수이고,
그중 가장 큰 절댓값이 $\rho_{\mathrm{int}}$ 입니다.

$$\lambda_k(\tilde B) = i\,s_k, \qquad \max_k \lvert s_k\rvert = \rho_{\mathrm{int}}$$

$\tilde B$ 가 정규 행렬이므로 위 노름은 고윳값으로 곧바로 나옵니다.

$$(1-\sigma)I - \sigma\tilde B \ \text{의 고윳값} = (1-\sigma) - i\sigma s_k$$

$$\varsigma(\sigma) = \max_k \sqrt{(1-\sigma)^2 + \sigma^2 s_k^2}$$

가장 큰 $\lvert s_k\rvert$ 가 최댓값을 정하므로

$$\boxed{\ \varsigma(\sigma) = \sqrt{(1-\sigma)^2 + \sigma^2\rho^2}\ }
\qquad (\rho = \rho_{\mathrm{int}})$$

### 1.7 최소점을 구한다

제곱을 미분하는 편이 쉽습니다.  제곱근이 단조증가라 최소점이 같습니다.

$$\frac{d}{d\sigma}\Bigl[(1-\sigma)^2 + \sigma^2\rho^2\Bigr]
= -2(1-\sigma) + 2\sigma\rho^2 = 0$$

$$-1 + \sigma + \sigma\rho^2 = 0$$

$$\sigma(1 + \rho^2) = 1$$

$$\boxed{\ \sigma^{*} = \frac{1}{1 + \rho^2}\ }$$

그때의 축소율을 구합니다.  먼저 첫 항입니다.

$$1 - \sigma^{*} = 1 - \frac{1}{1+\rho^2} = \frac{\rho^2}{1+\rho^2}$$

$$(1 - \sigma^{*})^2 = \frac{\rho^4}{(1+\rho^2)^2}$$

둘째 항입니다.

$$(\sigma^{*})^2\rho^2 = \frac{\rho^2}{(1+\rho^2)^2}$$

더합니다.

$$\varsigma(\sigma^{*})^2 = \frac{\rho^4 + \rho^2}{(1+\rho^2)^2}
= \frac{\rho^2(\rho^2 + 1)}{(1+\rho^2)^2} = \frac{\rho^2}{1+\rho^2}$$

$$\boxed{\ \varsigma_{\min} = \frac{\rho}{\sqrt{1+\rho^2}}\ }$$

### 1.7a 예측한 만큼 안 줄면 되돌아온다

1.7 절까지는 **걸음을 정하는 것**만 했습니다.  정하고 나서 실제로
얼마나 줄었는지는 안 봤습니다.

### 왜 봐야 하는가

1.2 절이 가장 작게 만든 것은 이것입니다.

$$\varsigma(\sigma) = \frac{\lVert \tilde{\mathbf F} + \tilde J\,\delta\mathbf u_\sigma\rVert}
{\lVert\tilde{\mathbf F}\rVert}$$

분자는 **선형 모형이 예측한 잔차**입니다.  실제 잔차가 아닙니다.
$F$ 가 비선형이면 그 예측이 빗나갈 수 있고, 그때 붙드는 것이 없습니다.

### 실제 값을 재는 법

한 걸음 밟은 자리에서 잔차를 다시 재면 됩니다.

$$\varsigma_{\text{실제}} = \frac{\lVert F(u + \sigma\,\delta u)\rVert}{\lVert F(u)\rVert}$$

조립 한 번이면 나옵니다.  고윳값 계산이 없습니다.

### 어긋나면 무슨 뜻인가

$\varsigma_{\text{실제}}$ 가 예측보다 크면 예측만큼 안 준 것입니다.
그것은 걸음을 정할 때 쓴 $\rho$ 가 실제보다 **작았다**는 뜻입니다.

### 맞는 $\rho$ 를 거꾸로 구한다

1.6 절의 식에서 $\varsigma$ 와 $\sigma$ 는 알고 $\rho$ 만 모릅니다.
그러니 $\rho$ 에 대해 풀면 됩니다.

$$\varsigma_{\text{실제}}^2 = (1-\sigma)^2 + \sigma^2\rho_{\text{유효}}^2$$

$$\boxed{\ \rho_{\text{유효}}^2 = \frac{\varsigma_{\text{실제}}^2 - (1-\sigma)^2}{\sigma^2}\ }$$

$\rho$ 를 재는 비용은 고윳값 때문인데, **잔차 노름 하나가 그것을 대신
알려 줍니다.**

### 다시 걸음을 정한다

새 식이 아닙니다.  1.7 절이 준 같은 식에 맞는 $\rho$ 를 넣습니다.

$$\boxed{\ \sigma_{\text{새}} = \min\left(\sigma,\ \frac{1}{1+\rho_{\text{유효}}^2}\right)\ }$$

$\min$ 을 두는 까닭은 부호 제한 $\sigma_{\chi}$ 가 더 작을 수 있어서입니다.

### 숫자를 넣은 보기

$\rho = 0.5$ 라 하고 걸음을 정하면 이렇게 됩니다.

$$\sigma = \frac{1}{1+0.25} = 0.8 \qquad \varsigma_{\text{예측}} = 0.447$$

곧 **80% 만 가고 잔차가 0.447 배로 준다**는 뜻입니다.

밟아 보니 잔차가 $0.6$ 배로만 줄었다고 합시다.  그러면

$$\rho_{\text{유효}}^2 = \frac{0.6^2 - 0.2^2}{0.8^2} = \frac{0.36-0.04}{0.64} = 0.5$$

$$\sigma_{\text{새}} = \frac{1}{1+0.5} = 0.667$$

$$\text{80% 가려던 것을 66.7% 로 줄여 다시 갑니다}$$

### 얼마나 어긋나야 어긋난 것인가

$\varsigma_{\text{실제}}$ 가 예측보다 조금이라도 크면 되돌린다고 하면 안
됩니다.  **그 「조금」을 얼마나 믿을 수 있는지를 먼저 봐야 합니다.**

$\varsigma$ 는 잔차의 비이고, 잔차는 $\delta u$ 로 계산합니다.  그런데
$\delta u$ 는 선형 방정식을 `LinTol` 만큼만 풀어서 얻은 것입니다.
2.5 절이 그 값을 정합니다.

$$\text{선형해를 } \texttt{LinTol} \text{ 만큼만 풀었으므로 } \varsigma \text{ 도 그만큼만 압니다}$$

그보다 작은 차이를 놓고 「예측이 빗나갔다」고 하는 것은 모르는 자리를
가지고 다투는 것입니다.

$$\varsigma_{\text{실제}} \;\le\; \varsigma_{\text{예측}}\bigl(1 + \texttt{LinTol}\bigr)
\;\Longrightarrow\; \text{되돌리지 않는다}$$

### 최소점 근처는 평평하다

$\sigma^{*}$ 는 $\varsigma$ 의 최소점입니다.  최소점에서는 기울기가 0 이므로,
$\sigma$ 를 $\delta$ 만큼 더 다듬어도 $\varsigma$ 는 $\delta^2$ 규모로만 좋아집니다.

$$\text{끝자리를 따라갈 값이 아닙니다}$$

### 실제로 그랬다

```
1 번째   sigma 0.999970 -> 0.997485   예측 0.0055  실제 0.0502
2 번째   sigma 0.997485 -> 0.997359   예측 0.0502  실제 0.0514
3 번째   sigma 0.997359 -> 0.997352   예측 0.0514  실제 0.0515
4 번째부터  sigma 0.997352 -> 0.997352  (여덟 번 더)
```

세 번째까지가 뜻이 있고, 그 뒤로는 끝자리만 기어갑니다.  조립을
여덟 번 더 하고 얻는 것이 없습니다.

`LinTol` 은 손으로 고른 값이 아닙니다.  2.5 절이 $\rho$ 와 `ResTol` 로
유도한 값이고, $\rho$ 가 작으면 더 꼼꼼히, 크면 헐렁하게 봅니다.

### 언제 끝나고 언제 안 끝나는가

$\rho_{\text{유효}} > \rho$ 이므로 $\sigma$ 는 되돌릴 때마다 엄격히 줄어듭니다.
그런데 **그것만으로는 끝난다는 보장이 안 됩니다.**

$\sigma$ 가 작을 때 잔차를 펼쳐 보겠습니다.  $g = J\,\delta u$ 라 두면

$$\varsigma_{\text{실제}}^2 = 1 + 2\sigma a + \sigma^2 b,
\qquad a = \frac{F^{\mathsf T} g}{\lVert F\rVert^2}$$

여기서 $a$ 는 잔차 $F$ 와 그 방향 $g$ 가 얼마나 반대를 향하는가입니다.
잔차를 줄이는 방향이면 음수여야 합니다.

$$(1-\sigma)^2 = 1 - 2\sigma + \sigma^2$$

두 값을 빼서 $\sigma^2$ 으로 나누면 이렇게 됩니다.

$$\rho_{\text{유효}}^2 = \frac{2(a+1)}{\sigma} + (b-1)$$

$a+1$ 이 0 보다 크면 $\sigma$ 가 줄어들 때 $\rho_{\text{유효}}^2$ 이 그만큼
커집니다.  $\sigma$ 를 반으로 줄이면 $\rho_{\text{유효}}^2$ 이 두 배가 되고,
그러면 $\sigma_{\text{새}}$ 도 다시 반이 됩니다.  **끝없이 되풀이됩니다.**

### $a+1>0$ 은 무슨 뜻인가

「이 방향으로는 아무리 조금 가도 잔차가 안 준다」는 뜻입니다.
곧 걸음의 크기 문제가 아니라 **방향의 문제**입니다.

방향이 못 믿을 것이 되는 까닭은 격자가 이 상태를 못 담기 때문입니다.
실제로 그 자리에서 $\nu_{\max} = 2.156$ 이었습니다.

```
M6-n2   Wmax 2.1560
M7-n1   sigma 0.007988 -> 0.003961 -> ... -> 0.000056
        줄어야 0.9999 인데 0.9999 다
```

### 그래서 격자를 먼저 본다

$$\nu_{\max} > 1 \;\Longrightarrow\; \text{되돌리지 않는다}$$

`trustRegionStep.m` 머리말이 그 경우를 이미 적어 두었습니다.

> 그 상황은 격자 부족이고 $\sigma$ 으로 고칠 수 없다.

답은 h-정제입니다.  걸음을 줄이는 것이 아닙니다.

새 상수를 안 씁니다.  $\nu_{\max} \le 1$ 은 3.4 절이 이미 정한 판정이고,
`trustRegionStep` 이 `Insufficient` 로 이미 내주고 있습니다.

### 격자가 충분할 때는 끝난다

$\nu_{\max} \le 1$ 이면 격자가 계수 변화를 담으므로 방향을 믿을 수 있고,
$a+1$ 이 0 보다 작아집니다.  그러면 $\sigma$ 가 줄어들 때 $\rho_{\text{유효}}$ 가
유한한 값으로 모이고, $\sigma_{\text{새}}$ 도 0 보다 큰 자리에 멈춥니다.

시간 간격을 다시 밟는 규칙이 $\Phi$ 의 단조성으로 끝나는 것과 같은
자리입니다.

### 비용

예측이 맞으면 한 번도 안 돕니다.  다시 밟을 때만 조립이 한 번 더
듭니다.  고윳값 계산은 없습니다.

### 이미 있던 것과 새로 만든 것

| 무엇 | 어디에 있었나 |
|---|---|
| $\varsigma(\sigma)$ 의 식 | 1.6 절.  이미 있었다 |
| $\sigma = 1/(1+\rho^2)$ | 1.7 절과 `AdaptiveDamper.m`.  이미 있었다 |
| $\varsigma_{\min}$ | `adaptiveTolerances.m` 이 내고 있었으나 **아무도 안 썼다** |
| 견주고 되돌아오는 자리 | **이것만 새로 만들었다** |

### 걸음을 붙드는 일은 감쇠가 맡는다

3.4a 절이 「$\nu_{\max} \le 1$ 은 걸음의 조건이 아니다」라고 했습니다.
그 말이 맞으려면 걸음을 붙드는 일을 감쇠가 해야 하는데, 감쇠는 선형
모형만 보고 있었습니다.  이 절이 그 빈 자리를 채웁니다.

### 1.8 이것이 뜻하는 것

$$\rho \text{ 가 아무리 커도 } \varsigma_{\min} < 1 \text{ 입니다}$$

$\rho^2 < 1 + \rho^2$ 이므로 분자가 분모보다 늘 작기 때문입니다.

$$\therefore\ \sigma^{*} \text{ 로 줄이면 \textbf{반드시} 수렴합니다}$$

감쇠를 안 하면 ($\sigma = 1$) 축소율이 $\rho$ 가 되므로, $\rho \ge 1$ 이면
잔차가 안 줄어듭니다.  **감쇠가 그 벽을 없앱니다.**

| $\rho$ | $\sigma = 1$ | $\sigma = \sigma^{*}$ |
|---|---|---|
| 0.1 | 0.100 | 0.0995 |
| 1 | 1.000 (안 줄어듦) | 0.707 |
| 5 | 5.000 (발산) | 0.981 |

### 1.9 $\rho$ 가 작으면 걸음이 1 에 가깝다

$$\sigma^{*} = \frac{1}{1+\rho^2} \approx 1 - \rho^2$$

$\rho = 0.011$ 이면 $\sigma^{*} = 0.99987$ 입니다.  **거의 안 줄이는 것입니다.**

이것이 이 방법의 값어치입니다.  전처리가 잘 들어 $\rho$ 가 작으면
감쇠가 걸릴 일이 없고, 뉴턴이 제 속도로 갑니다.

## 2. 얼마나 정확히 풀 것인가

### 2.1 왜 조절하는가

선형 방정식을 아주 정확히 풀어도, **방향 자체가 이미 근사입니다.**
방향보다 더 정확히 푸는 것은 낭비입니다.

$$\text{그 낭비 지점을 } \rho \text{ 로 계산할 수 있습니다}$$

### 2.2 기준을 무엇으로 삼는가

잔차를 `ResTol` 까지 줄이는 데 필요한 반복 횟수를 봅니다.

$$k = \frac{\ln(1/\text{ResTol})}{\ln(1/\varsigma_{\min})}$$

분모를 $\rho$ 로 쓰면 이렇게 됩니다.

$$\ln\frac{1}{\varsigma_{\min}} = \ln\frac{\sqrt{1+\rho^2}}{\rho}
= \frac{1}{2}\ln\left(1 + \frac{1}{\rho^2}\right)$$

> **이 둘에는 이름을 안 줍니다.**  한 식에서 한 번 쓰이고 마는 중간값이라
> 기호만 늘어납니다.  `SYMBOLS.md` 4절 참조.

### 2.3 「한 번만 더」를 기준으로 삼는다

$\rho$ 를 조금 잘못 재거나 선형해를 조금 덜 정확히 풀면 축소율이 나빠집니다.
그러면 반복이 늘어납니다.

$$\text{그 늘어남이 \textbf{한 번}을 안 넘게 하는 값을 씁니다}$$

$$\delta k = \frac{\ln(1/\text{ResTol})\cdot e_\varsigma}{\bigl[\ln(1/\varsigma_{\min})\bigr]^2} = 1$$

여기서 $e_\varsigma$ 는 축소율이 나빠진 정도입니다.  아래 첨자는 어느 양의
오차인지를 가리킵니다.  $e_\lambda$ 는 고윳값의 오차, $e_\varsigma$ 는 축소율의 오차입니다.

**왜 한 번인가.**  0 으로 하면 아무리 정확해도 모자라고, 두 번으로 하면
느슨합니다.  한 번은 「이 오차 때문에 딱 한 걸음 더 걷는다」는 뜻이고,
그것이 받아들일 만한 가장 작은 손해입니다.

### 2.4 $\rho$ 를 얼마나 정확히 재면 되는가

$\rho$ 를 고윳값으로 잴 때 상대 허용오차를 $\text{tol}$ 이라 하면,
그 오차가 축소율에 이렇게 전해집니다.

$$e_\lambda = \frac{\rho^2}{1+\rho^2}\,\text{tol}$$

$$e_\varsigma = \frac{e_\lambda^2}{2\rho^2}$$

**왜 제곱이 나오는가.**  $\varsigma$ 가 $\sigma^{*}$ 에서 최소이므로 그 점에서
1차 항이 0 입니다.  2차부터 나타납니다.

$\delta k = 1$ 로 놓고 풀면

$$\boxed{\ \text{RhoTol} = \frac{1+\rho^2}{\rho}\,\ln\frac{1}{\varsigma_{\min}}
\sqrt{\frac{2}{\ln(1/\text{ResTol})}}\ }$$

### 2.5 선형해를 얼마나 정확히 풀면 되는가

같은 기준을 선형해에 적용하면

$$\boxed{\ \text{LinTol} = \frac{\rho\bigl[\ln(1/\varsigma_{\min})\bigr]^2}
{\ln(1/\text{ResTol})}\ }$$

**둘 다 같은 데서 나왔습니다.**  「반복이 한 번만 더 늘어난다」입니다.

### 2.6 $\rho$ 를 아예 안 재도 될 때

$$\text{RhoTol} \ge 1 \ \Longrightarrow\ \text{잴 필요가 없다}$$

허용오차가 1 을 넘는다는 것은 $\rho$ 를 어림잡아도 반복이 한 번밖에 안
늘어난다는 뜻입니다.  그러면 재는 비용이 아깝습니다.

`adaptiveTolerances` 가 `SkipRho` 로 알려 줍니다.

---

### 2.6a  $\rho \le 0$ 은 「감쇠 없음」이 아니라 「모른다」이다

2.6 절이 정한 것은 이것입니다.

$$\text{RhoTol} \ge 1 \;\Longrightarrow\; \rho \text{ 를 잴 이유가 없다}$$

**그 판단은 그 상태에 대한 것입니다.**  다음 상태의 $\rho$ 가 얼마인지는
지난 $\rho$ 로 알 수 없습니다.

특히 $\rho = 0$ 은 아무 정보도 없는 값입니다.

$$a = \tfrac12\ln\bigl(1+1/\rho^2\bigr) \;\longrightarrow\; \infty$$

`RhoTol` 을 계산할 수조차 없습니다.  그런 값을 다음 판단의 근거로
삼으면 `SkipRho` 가 계속 참이 되어 **영영 0 에 머뭅니다.**  그러면
감쇠 인자가 늘 1 이 되어 감쇠가 죽습니다.

$$\text{유도는 「한 번 건너뛴다」를 허락했지 「영영 안 잰다」를 허락하지 않았습니다}$$

### 실제로 그랬다

$u$ 가 어디서나 0 인 자리에서 출발하면 $\nu = 0$ 이라 자코비안이 대칭이고 $\rho = 0$ 이
**참입니다.**  그런데 그 뒤로 다시는 안 쟀습니다.

| 단계 | $\nu_{\max}$ | $\rho$ | $\sigma_{\text{감쇠}}$ |
|---|---|---|---|
| 1 | 0.0000 | 0 | 1 |
| 2 | 0.7475 | 0 | 1 |
| 3 | 1.5506 | 0 | 1 |

두 번째 단계에서 이미 $u \ne 0$ 이라 반대칭부가 생겼는데 아무도 안
봤습니다.  붙드는 것이 없으니 한 걸음에 멀리 가 격자가 못 담는 자리로
갔습니다.

### 모를 때 돌아갈 자리

부트스트랩 값 $1.0$ 입니다.  $\rho < 1$ 이 보장 경계이므로 거기서 다시
재면 됩니다.  새 상수가 아닙니다.

$$\rho \le 0 \ \text{또는 유한하지 않음} \;\Longrightarrow\; \rho_{\text{prev}} \leftarrow 1.0$$

## 3. 구조가 안 깨지는 최대 걸음

### 3.1 무엇을 지키려는가

자코비안의 비대각이 음수여야 좋은 성질이 유지됩니다.
이 성질이 깨지면 $S$ 가 양정치를 잃고, 그러면 $\rho_{\mathrm{int}}$ 자체가
정의되지 않습니다.

$$\hat J_{ij} = -D_{ij}\Bigl(P_{\text{eff}} + \frac{\partial P_{\text{eff}}}{\partial u_j}\delta u\Bigr)$$

$D_{ij} > 0$ 이므로 괄호 안의 부호만 보면 됩니다.

### 3.2 괄호 안을 정리한다

$P_{\text{eff}} = \dfrac{2ab}{a+b}$ 로 두고 ($a = p_i$, $b = p_j$) 미분합니다.

$$\frac{\partial P_{\text{eff}}}{\partial u_j} = \frac{2a^2}{(a+b)^2}\,
\left.\frac{\partial p}{\partial u}\right\rvert_j$$

괄호에 넣고 묶습니다.

$$P_{\text{eff}} + \frac{\partial P_{\text{eff}}}{\partial u_j}\delta u
= \frac{2a}{(a+b)^2}\Bigl[b(a+b)
+ a\left.\frac{\partial p}{\partial u}\right\rvert_j\delta u\Bigr]$$

앞 인자가 양수이므로 **대괄호 안의 부호만 보면 됩니다.**

### 3.3 무차원으로 바꾼다

$a$ 를 1 로 규격화하고 $\zeta_{ij} = \ln(b/a)$ 로 두면 $b = e^{\zeta_{ij}}$ 입니다.

$$\nu_j = \left.\frac{\partial\ln p}{\partial u}\right\rvert_j\delta u$$

대괄호를 이 기호로 다시 쓰면

$$e^{\zeta_{ij}}(1 + e^{\zeta_{ij}}) + e^{\zeta_{ij}}\nu_j = e^{\zeta_{ij}}\bigl(\nu_j + 1 + e^{\zeta_{ij}}\bigr)$$

$e^{\zeta_{ij}} > 0$ 이므로 조건은 이것입니다.

$$\boxed{\ \nu_j + 1 + e^{\zeta_{ij}} > 0\ }$$

### 3.4 여기서 1 이 나온다

$e^{\zeta_{ij}} > 0$ 이므로, $\nu_j > -1$ 이기만 하면 위 부등식이 저절로 성립합니다.

$$\therefore\ \lvert \nu_j\rvert \le 1 \ \Longrightarrow\ \text{안전}$$

반대쪽 노드도 같은 방식으로 보면 $\lvert \nu_i\rvert \le 1$ 이 나옵니다.
둘을 합치면

$$\boxed{\ \max\bigl(\lvert \nu_i\rvert,\ \lvert \nu_j\rvert\bigr) \le 1\ }$$

$$\text{이 1 은 부등식을 푼 결과이지 사람이 고른 값이 아닙니다}$$

### 3.5 걸음으로 바꾼다

$\nu$ 는 $\delta u$ 에 비례하므로, 걸음을 $\sigma$ 배 하면 $\nu$ 도 $\sigma$ 배입니다.

$$\sigma_{\text{부호}} = \frac{1}{\max\lvert \nu\rvert}
\qquad (\max\lvert \nu\rvert > 1 \text{ 일 때})$$

$\max\lvert \nu\rvert \le 1$ 이면 걸림이 없으므로 $\sigma_{\text{부호}} = 1$ 입니다.

### 3.4a 세 가지를 뭉치면 안 된다

걸음과 얽혀 있는 값이 셋인데, 셋이 서로 다른 것을 지킵니다.

| | 무엇을 지키나 | 어디서 | 무엇에 대한 조건인가 |
|---|---|---|---|
| $\sigma_{\chi}$ | $\chi_{ij} > 0$ | 3.2 절 | **행렬의 구조** |
| $\sigma_{\text{감쇠}}$ | 잔차 축소율 최소 | 1.2 절 | **걸음의 크기** |
| $\nu_{\max} \le 1$ | $h\lvert\nabla\ln p\rvert \le 1$ | 3.4 절 | **격자의 해상도** |

### 걸음의 조건은 앞의 둘뿐이다

$$\sigma = \min\bigl(\sigma_{\chi},\ \sigma_{\text{감쇠}}\bigr)$$

$\nu_{\max} \le 1$ 은 **걸음의 조건이 아닙니다.**  「이 격자가 이 해를
담을 수 있는가」를 묻는 것이고, 담을 수 없으면 답은 격자를 늘리는
것이지 걸음을 줄이는 것이 아닙니다.

`trustRegionStep.m` 이 그렇게 적어 두었습니다.

> $\lvert\nu^0\rvert > 1$ 인 간선은 제약에서 뺀다.  그 상황은 격자 부족이고
> $\sigma$ 으로 고칠 수 없다.

### 뉴턴이 헤매지 않게 붙드는 것은 감쇠다

1.1 절이 그것을 명시합니다.

> $\tilde J$ 대신 $S$ 로 방향을 잡으므로 그 방향은 정확하지 않습니다.
> **틀린 방향으로 끝까지 가면 넘어갑니다.**

$\sigma_{\chi}$ 는 구조를 지킬 뿐, 걸음을 붙드는 물건이 아닙니다.

### 실제로 그 둘이 뭉쳐 있었다

대리 조건 $\lvert\nu\rvert \le 1$ 을 쓰던 동안, $\sigma_{\chi}$ 가 감쇠의 일을
대신하고 있었습니다.  $\nu$ 가 0 에서 출발하므로 그 규칙이 있으면
$\nu$ 가 1 을 영영 못 넘기 때문입니다.

$k_{nl}=4$ 에서 $\sigma_{\min} = 0.27$ 로 걸음이 세게 깎이고 있었는데,
그것이 $\chi$ 를 지키려던 것이 아니라 걸음을 붙들고 있었습니다.

$$\text{그래서 감쇠가 죽어 있어도 굴러갔습니다}$$

3.5a 절대로 $\sigma_{\chi}$ 를 제자리로 돌리자 감쇠가 죽어 있다는 사실이
드러났습니다.  그 까닭은 2.6a 절에 적었습니다.

### 3.5a 걸음은 대리 경계가 아니라 참 조건을 쓴다

3.4 절의 $\lvert\nu\rvert \le 1$ 은 **충분조건**입니다.  참 조건은 3.2 절의
두 부등식이고, 그 경계는 더 바깥에 있습니다.

$$\nu_i \;<\; 1 + e^{-s} = 1 + \frac{p_i}{p_j}
\qquad
\nu_j \;>\; -\bigl(1 + e^{s}\bigr) = -\Bigl(1 + \frac{p_j}{p_i}\Bigr)$$

$e^{s} > 0$ 이므로 $s$ 가 무엇이든 이렇습니다.

$$1 + e^{-s} > 1 \qquad -(1+e^{s}) < -1$$

$$\text{참 상자가 대리 상자를 \textbf{품습니다}}$$

**대리 경계로 걸음을 정하면 갇힙니다.**  걸음 식이 이렇게 생겼기
때문입니다.

$$\sigma_e = \frac{1 - \nu^0}{\delta\nu}$$

이 값을 쓰면 그 간선이 **정확히** $\nu = 1$ 에 놓입니다.  다음 걸음에서
분자가 0 이 되어 $\sigma$ 가 사라집니다.

$$\text{걸음 규칙이 스스로 경계에 세워 놓고 갇힙니다}$$

실제로 그랬습니다.

```
sig 4.580e-01 | Wmax 0.9935
sig 7.152e-16 | Wmax 1.0000   -> 미시 교착
```

그 자리는 참 경계가 아닙니다.  $\nu_i = 1$ 에서 여유가 $p_i/p_j > 0$
남아 있습니다.  갈 곳이 있는데 못 간 것입니다.

### 제약은 간선마다 한쪽씩이다

3.2 절을 보면 $\hat J_{ij}$ 는 $\nu_j$ 만, $\hat J_{ji}$ 는 $\nu_i$ 만 담습니다.

| 무엇 | 막히는 쪽 | 반대쪽으로 가면 |
|---|---|---|
| $\nu_i$ | 위로만 | $\hat J_{ji}$ 가 더 음수가 된다 |
| $\nu_j$ | 아래로만 | $\hat J_{ij}$ 가 더 음수가 된다 |

막을 이유가 없으므로 한쪽씩만 제약합니다.

### 격자 판정은 그대로 1 이다

$\nu_{\max} \le 1$ 은 $h\lvert\nabla\ln p\rvert \le 1$ 이라는 **다른 물음**입니다.
`legacy/L_08_hrefine_spec.md` 의 실측 넷이 그 값에 맞춰져 있습니다.

$$\text{걸음 상한만 참 조건으로 바꿉니다}$$

### 실측

r-적응을 켠 과도 풀이 넷입니다.  대리 경계를 쓸 때는 넷 중 하나만
끝까지 갔습니다.

| $\delta t$ | 걸음 | 푼 뒤 $\nu_{\max}$ | 정제 | 사유 |
|---|---|---|---|---|
| 0.1 | 5 | 0.9933 | 4 | TEnd 도달 |
| 0.05 | 10 | 0.9980 | 6 | TEnd 도달 |
| 0.025 | 20 | 0.9998 | 6 | TEnd 도달 |
| 0.0125 | 40 | 0.9936 | 6 | TEnd 도달 |

넷 다 끝까지 갑니다.  $\nu_{\max}$ 가 1 바로 아래에 머무는데, 그것이
정상입니다.  h-정제가 1 을 넘지 않게 붙들고, 걸음 상한은 그보다
바깥인 참 경계를 보므로 갇히지 않습니다.

### 3.6 감쇠와 어떻게 합치는가

$$\sigma = \min\Bigl(\sigma_{\text{부호}},\ \frac{1}{1+\rho^2}\Bigr)$$

**둘은 서로 다른 것을 막습니다.**

| 값 | 막는 것 |
|---|---|
| $\sigma_{\text{부호}}$ | 비대각의 부호가 뒤집히는 것 |
| $1/(1+\rho^2)$ | 잔차가 안 줄어드는 것 |

구조가 무너지면 $\rho$ 를 잴 수조차 없으므로, 앞의 것이 더 근본적입니다.
그래서 둘 중 작은 쪽을 씁니다.

## 4. 격자를 얼마나 늘릴 것인가

### 4.1 무엇이 문제인가

$\max\lvert \nu\rvert > 1$ 이면 걸음을 줄여야 합니다.  그런데 걸음을 줄이면
뉴턴이 느려집니다.

$$\text{걸음을 줄이지 말고 } \lvert \nu\rvert \text{ 를 줄이면 됩니다}$$

$\nu$ 는 간선을 건너는 동안 $\ln p$ 가 얼마나 변하는지입니다.
간선이 짧아지면 그 변화도 줄어듭니다.

### 4.2 얼마나 짧게 해야 하는가

간선 길이는 노드 수에 반비례합니다.

$$h \propto \frac{1}{N_x - 1}$$

$\nu$ 는 간선 길이에 비례하므로, 노드를 늘리면 $\nu$ 가 그만큼 줄어듭니다.

$$\nu_{\max}^{\text{새로}} = \nu_{\max}\times\frac{N_x - 1}{N_x^{\text{새로}} - 1}$$

이것이 1 이 되게 놓습니다.

$$\nu_{\max}\times\frac{N_x - 1}{N_x^{\text{새로}} - 1} = 1$$

$$N_x^{\text{새로}} - 1 = (N_x - 1)\,\nu_{\max}$$

$$\boxed{\ N_x^{\text{새로}} = \bigl\lceil 1 + (N_x - 1)\nu_{\max} \bigr\rceil\ }$$

$$\text{여유를 위해 곱하는 상수가 없습니다.  필요한 만큼만입니다}$$

### 4.3 왜 유한 번에 끝나는가

한 번 늘릴 때마다 $\nu_{\max}$ 가 이 비율로 줄어듭니다.

$$\gamma_h = \frac{N_x - 1}{N_x^{\text{새로}} - 1}$$

$\lceil\cdot\rceil$ 때문에 조금 더 늘어나므로 $\gamma_h$ 가 필요한 것보다 조금
작습니다.  그러니 $\nu_{\max}$ 가 1 밑으로 확실히 내려갑니다.

**해가 달라져서 $\nu_{\max}$ 가 도로 커질 수는 있습니다.**  노드가 늘면 해도 달라지기
때문입니다.  그래서 오르내리는 것이 정상이고, 그 이유로 멈추지 않습니다.

## 5. 시간 간격을 얼마로 할 것인가

### 5.1 시간 항이 무엇을 바꾸는가

`60_유도_상한.md` 6절에서 본 대로입니다.

$$\operatorname{sym}(\tilde J_{\delta t}) = S + \frac{1}{\delta t}M,
\qquad \operatorname{skew}(\tilde J_{\delta t}) = A$$

$$\rho_{\mathrm{int}}(\delta t) = \sup_{\mathbf w}
\frac{\lvert\mathbf w^{*}A\mathbf w\rvert}{\mathbf w^{*}(S + \frac{1}{\delta t}M)\mathbf w}$$

$$\text{분자는 그대로, 분모만 커집니다}$$

$M \succ 0$ 이므로 $\delta t$ 를 줄이면 분모가 반드시 커지고, 따라서
$\rho_{\mathrm{int}}$ 가 반드시 줄어듭니다.

### 5.2 언제 1 밑으로 내려가는가

상한 A 를 시간 항이 있는 꼴로 다시 씁니다.

$$\rho_{\mathrm{int}}(\delta t) \le \max_i
\sqrt{\frac{\Phi_{ii}}{2(\gamma_i + \frac{\hat c_i c_i \tilde V_i}{\delta t})}}$$

**$\Phi_{ii}$ 가 시간 간격에 안 바뀝니다.**  $M$ 이 대각이라 비대각을 안 건드리고,
$\Phi_{ii}$ 는 비대각에서만 만들어지기 때문입니다.

이 값이 1 보다 작으려면

$$\frac{\Phi_{ii}}{2(\gamma_i + \frac{\hat c_i c_i\tilde V_i}{\delta t})} < 1$$

$$\Phi_{ii} < 2\gamma_i + 2\frac{\hat c_i c_i\tilde V_i}{\delta t}$$

$$\frac{1}{\delta t} > \frac{\Phi_{ii}/2 - \gamma_i}{\hat c_i c_i\tilde V_i}$$

모든 노드에서 성립해야 하므로 가장 큰 값을 취하고, 역수로 뒤집습니다.

$$\boxed{\ \delta t_{\max} = \min_i \frac{\hat c_i\,c_i\,\tilde V_i}{\Phi_{ii}/2 - \gamma_i}\ }$$

$$\delta t < \delta t_{\max} \text{ 이면 } \rho_{\mathrm{int}} < 1 \text{ 이 보장됩니다}$$

> **역수를 취하면 max 가 min 이 됩니다.**  분모가 가장 큰 값을 요구하는
> 노드가 곧 시간 간격을 가장 작게 만드는 노드입니다.

### 5.3 분모에 $\hat c_i$ 가 왜 들어가는가

**이 자리가 헷갈리기 쉽습니다.**

상한이 쓰는 $A$ 와 $S$ 는 $\hat C\hat J$ 에서 나온 것입니다.
그러니 시간 항도 $\hat C$ 를 통과한 뒤의 것이어야 합니다.

$$\hat C\hat J_{\delta t} = \hat C\hat J + \frac{1}{\delta t}\,\hat C M$$

$\hat C$ 와 $M$ 이 둘 다 대각이므로 곱도 대각입니다.

$$\hat C M = \operatorname{diag}\bigl(\hat c_i\,c_i\,\tilde V_i\bigr)$$

$$\therefore\ \text{상한이 쓰는 질량은 } \hat c_i c_i\tilde V_i \text{ 입니다}$$

$p$ 가 상수인 문제에서는 $\hat C \approx I$ 라 이 차이가 안 드러납니다.
그래서 놓치기 쉬운 자리입니다.

### 5.4 소스가 상수여도 시간 간격에 상한이 생긴다

$$\delta t_{\max} = \min_i \frac{\hat c_i c_i\tilde V_i}{\Phi_{ii}/2 - \gamma_i}$$

$\partial q/\partial u = 0$ 이면 $\gamma_i = 0$ 입니다.  그러면 분모가 $\Phi_{ii}/2$ 만
남아 상한이 없어질 것 같지만 아닙니다.

$$\Phi_{ii} = \sum_j \varepsilon_{ij}^2\,\chi_{ij}$$

$\Phi_{ii}$ 는 간선의 비대칭에서 오는 것이라 소스와 무관합니다.
격자가 만든 비대칭이 남아 있으면 $\varepsilon_{ij} \ne 0$ 이고,
그러면 $\Phi_{ii} > 0$ 입니다.

### 5.5 이것은 충분조건이다

$\delta t < \delta t_{\max}$ 이면 반드시 풀립니다.  그러나 **그보다 큰 시간
간격으로도 풀릴 수 있습니다.**  상한을 썼기 때문에 넉넉하게 잡혀 있습니다.

| 조건 | 무엇을 말하나 |
|---|---|
| $\delta t < \delta t_{\max}$ | 풀린다는 **보장** |
| $\delta t \ge \delta t_{\max}$ | 보장이 없다.  풀릴 수도 있다 |

### 5.6 재시도할 때 얼마나 올리는가

$\rho_{\mathrm{int}}$ 는 시간 간격을 줄이면 계속 줄어듭니다.  그러니 **상한 밑으로
내려가기만 하면 되고 얼마나 내려갈지는 상관이 없습니다.**

$$\delta t_{\text{다음}} = \operatorname{nextbelow}\bigl(\delta t_{\max}^{\text{새로}}\bigr)$$

부동소수에서 그 수보다 작은 가장 가까운 수입니다.  가장 적게 줄이는 것이
시간 간격을 가장 크게 남깁니다.

**여유 상수를 곱할 이유가 없습니다.**  곱하면 시간 간격이 그만큼 작아지고,
걸음 수가 그만큼 늘어납니다.

## 6. 다섯 값이 어디서 왔는지 한자리에

| 값 | 어디서 나왔나 | 사람이 고른 숫자 |
|---|---|---|
| $\sigma^{*} = 1/(1+\rho^2)$ | $\varsigma(\sigma)$ 의 최소점 | 없음 |
| $\text{RhoTol}$, $\text{LinTol}$ | 반복이 한 번만 더 늘어나는 지점 | 「한 번」 |
| $\max\lvert \nu\rvert \le 1$ | $\nu + 1 + e^{\zeta_{ij}} > 0$ 을 푼 결과 | 없음 |
| $N_x^{\text{새로}} = \lceil 1 + (N_x{-}1)\nu_{\max}\rceil$ | $\nu_{\max}$ 를 1 로 만드는 배수 | 없음 |
| $\delta t_{\max}$ | 상한 A 를 1 미만으로 만드는 시간 간격 | 없음 |

「한 번」 하나만 사람이 정한 것이고, 그것도 근거가 있습니다.
0 이면 아무리 정확해도 모자라고 2 면 느슨합니다.
