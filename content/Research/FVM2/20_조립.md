# 20. 조립

격자와 물성이 준비되면, 지금 놓인 해 $u$ 에서 **잔차**와 **자코비안**을 만듭니다.
그리고 자코비안의 비대칭을 두 갈래로 가릅니다.

| 가른 것 | 어디서 왔는가 | 어떻게 하는가 |
|---|---|---|
| 격자가 만든 비대칭 | 노드마다 쌍대 체적이 달라서 | 대각 배율 $\hat C$ 를 곱해 최대한 흡수한다 |
| 물리가 만든 비대칭 | $p$ 가 $u$ 에 의존해서 | **남겨 둔다.**  얼마나 큰지 재서 다룬다 |

**남는 것을 지우면 안 됩니다.**  그 안에 해가 어느 쪽으로 가야 하는지가
들어 있습니다.  다 없애면 푸는 문제가 달라집니다.
흡수할 수 있는 만큼만 흡수하고 나머지는 그대로 두는 것이 이 조립의 요점입니다.

## 이 문서가 다루는 파일

| 파일 | 하는 일 |
|---|---|
| `Purifier2D.m` | 조립 전체를 맡는다.  부르는 곳은 `assemble2D` 하나 |
| `assembleRobinFaces.m` | Robin 경계를 면 단위로 더한다 |
| `assembleRobinNodal.m` | 면으로 안 잡힌 나머지 노드를 채운다 |
| `AdjointCExtractor.m` | 격자 때문에 생긴 비대칭을 흡수할 $\hat C$ 를 구한다 |
| `AssembledSystem.m` | 조립이 낸 것을 통째로 담는 그릇 |
| `dirichletRowsOf.m` | 행렬의 생김새만 보고 Dirichlet 행을 가려낸다 |

## 1. 부르는 법

```matlab
eng = Purifier2D();
sys = eng.assemble2D('MeshM', mm, 'PhysM', pm, 'U_current', U);
```

시간 항을 함께 넣으려면 두 가지를 더 줍니다.

```matlab
sys = eng.assemble2D('MeshM', mm, 'PhysM', pm, 'U_current', U, ...
                     'InvDt', 1/dt, 'U_old', U_prev);
```

| 이름 | 뜻 | 안 주면 |
|---|---|---|
| `MeshM` | 격자 | 반드시 줘야 한다 |
| `PhysM` | 물성 | 반드시 줘야 한다 |
| `U_current` | 지금 놓인 해 | 반드시 줘야 한다 |
| `InvDt` | $1/\delta t$ | 0.  시간 항이 없는 정상 문제가 된다 |
| `U_old` | 직전 시각의 해 | 빈 배열.  `InvDt > 0` 이면 반드시 줘야 한다 |

## 2. 무엇이 나오는가 — `AssembledSystem`

돌려주는 것은 **그릇 하나**입니다.  푸는 데 쓰는 것 여덟이 들어 있습니다.

| 이름 | 기호 | 무엇 |
|---|---|---|
| `sys.CGJ` | $\hat C\hat G\hat J$ | 조립이 만든 원본 행렬.  비대칭 |
| `sys.T` | $\tilde J_{\text{pure}}$ | 그중 대칭인 부분 |
| `sys.K_int` | $\tilde A_{\text{int}}$ | 그중 반대칭인 부분 |
| `sys.C` | $\hat C$ | 노드마다 곱한 배율.  대각 행렬 |
| `sys.Res` | | 잔차.  이것이 0 이 되면 다 푼 것이다 |
| `sys.Eta` | | 비대칭 중 얼마만큼이 흡수됐는지 (0~1) |
| `sys.C_cap` | $c_i$ | 노드마다의 시간 항 계수 |
| `sys.IsDir` | | Dirichlet 노드에 참이 든 마스크 |

여기에 하나가 더 있습니다.  **쓸 때만 만들어집니다.**

| 이름 | 기호 | 무엇 |
|---|---|---|
| `sys.GJ` | $\hat G\hat J$ | $\hat C^{-1}\,\hat C\hat G\hat J$.  배율을 되돌린 것 |

### 2.0 재는 데 쓸 값 둘

푸는 데는 안 쓰고 재는 데만 쓰는 값들입니다.  노드마다의 것과
간선마다의 것으로 나눠 담습니다.  유한체적법의 두 축과 같습니다.

| `sys.Node` | 무엇 |
|---|---|
| `V` | 노드가 맡은 넓이 |
| `Q` | 소스가 그 노드에 만든 양 |
| `Flux` | 이웃에서 그 노드로 들어온 양 |
| `Robin` | Robin 경계가 그 노드에 넣어 준 양 |
| `IsNeu` | Robin 노드에 참 |
| `RegionID` | 그 노드가 어느 영역인가 |

| `sys.Edge` | 무엇 |
|---|---|
| `I` `J` | 간선의 두 노드.  상삼각이고 양끝이 Dirichlet 이 아니다 |
| `D` | 간선의 기하 계수 |
| `Pi` `Pj` | 간선 중점에서 두 값으로 잰 물성 |
| `dPi` `dPj` | 그 자리의 도함수 |
| `Peff` | 둘의 조화평균 |

**왜 담아 두는가.**  옛 판은 `SystemAnalyzer2D` 와 `trustRegionStep` 이
이것들을 밖에서 다시 만들었습니다.  물성을 다시 평가하고 조화평균을
다시 내고 경계를 다시 훑었습니다.

$$\text{조립이 이미 아는 값을 세 곳에서 따로 만들고 있었습니다}$$

담아 두면 재는 쪽이 물성을 몰라도 됩니다.  `12_후처리독립.md` 3 장에
그 기록이 있습니다.

### 2.1 왜 그릇 하나로 돌려주는가

여러 값을 자리 순서대로 늘어놓아 돌려주면, 받는 쪽마다 몇 개를 받을지가
제각각이 됩니다.  그러면 뒤에 무엇을 하나 더 붙였을 때 어디까지 영향이
가는지 알 수 없습니다.  이름으로 꺼내면 그럴 일이 없습니다.

**그리고 원본을 함께 담아야 합니다.**

$\hat C\hat G\hat J$ 가 조립이 만든 원본이고, `T` 는 거기서 `K_int` 를 뺀
것입니다.  원본을 안 주고 조각만 주면 쓰는 쪽이 `T + K_int` 로 되붙여야 합니다.
값이 0 이 아닌 자리가 오만 개가 넘는 희소 행렬을 뉴턴 한 걸음마다 몇 번씩
더하는 셈입니다.

원본을 함께 담으면 희소 행렬 하나가 더 늘지만 그 덧셈이 없어집니다.

### 2.2 한 번 만들면 안에 든 값을 바꿀 수 없습니다

`AssembledSystem` 의 속성은 모두 `SetAccess = immutable` 입니다.
조립 결과는 만든 뒤 바뀌지 않으므로 그렇게 두었습니다.
`MeshSnapshot` 도 같은 규약입니다.

### 2.3 상한을 재는 셈법 셋이 함께 들어 있습니다

```matlab
m          = sys.spectrumMetrics(...)           % 고윳값 분포와 조건수
[rho, inf] = sys.rhoIntAdaptive(rho_prev, tol)  % rho_int 를 잰다
[dtm, dg]  = sys.dtBound(V_node, ...)        % 시간 간격 상한을 낸다
```

**셋을 여기 둔 까닭은 쓰는 값이 전부 이 그릇 안에 있기 때문입니다.**

| 셈법 | 쓰는 값 |
|---|---|
| `spectrumMetrics` | `T`, `C`, `K_int` |
| `rhoIntAdaptive` | `T`, `K_int` |
| `dtBound` | `T`, `K_int`, `C`, `C_cap`, `IsDir` + 격자에서 받는 `V_node` |

반대로 `trustRegionStep` 은 밖에 함수로 두었습니다.  그것은 격자와 물성으로
$\nu_j$ 를 만드는 것이 본체이고, 조립 결과는 간선 목록을 얻는 데만 씁니다.
보폭을 정하는 일은 뉴턴 한 걸음의 일이지 조립의 일이 아닙니다.

## 3. 부호 규약 — 먼저 못박고 갑니다

**부호를 하나라도 어긋나게 쓰면 뒤의 모든 것이 뒤집힙니다.**
그래서 여기서 정하고 갑니다.

### 3.1 지배방정식은 소스가 양수인 꼴

$$c(x,y)\,\frac{\partial u}{\partial t} = \nabla\cdot\bigl(p\nabla u\bigr) + q$$

$$\text{$q$ 가 소스 그 자체입니다.  발열이면 양수를 그대로 넣습니다}$$

열전도에서 흔히 쓰는 표기와 같습니다.

$$\nabla\cdot(\kappa\nabla T) + Q = 0 \qquad (Q > 0 \text{ 이 발열})$$

### 3.2 잔차는 오른쪽을 옮기고 부호를 뒤집은 것

$$\text{res} = -\nabla\cdot(p\nabla u) - q$$

$$c\,\frac{\partial u}{\partial t} + \text{res} = 0$$

이렇게 잡으면 자코비안이 이런 부호가 됩니다.

| | 부호 |
|---|---|
| 대각 $\hat J_{ii}$ | **양수** |
| 비대각 $\hat J_{ij}$ | **음수** |
| $\mathrm{sym}(\hat J)$ 의 내부 블록 | **양정치** |

$$\text{대각이 양수, 비대각이 음수인 이 꼴을 M-행렬이라 합니다}$$

### 3.3 게재 논문은 부호가 반대입니다

| | 게재 논문 | 이 코드 |
|---|---|---|
| 지배식 | $\nabla\cdot(p\nabla u) = q$ | $\nabla\cdot(p\nabla u) + q = 0$ |
| $q$ 의 뜻 | 부호가 뒤집힌 소스 | **소스 그 자체** |
| 잔차 | $R = \nabla\cdot(p\nabla u) - q$ | $\text{res} = -\nabla\cdot(p\nabla u) - q$ |
| 대각 | 음수 | **양수** |
| $\mathrm{sym}$ | 음정치 | **양정치** |

$$q_{\text{여기}} = -q_{\text{논문}} \qquad\Longrightarrow\qquad \text{res} = -R$$

**가리키는 대상은 같습니다.**  자코비안도 같고 걸음도 같습니다.
달라지는 것은 $q$ 를 넣을 때 부호를 뒤집어야 하는가뿐입니다.

### 3.4 왜 이 규약이 나은가

반응 항의 부호가 물리와 그대로 맞습니다.

$$\gamma_i \sim -\frac{\partial q}{\partial u}\tilde V_i$$

$$\gamma_i > 0 \iff \frac{\partial q}{\partial u} < 0 \iff \text{값이 오르면 소스가 줄어든다}$$

**값이 오르면 소스가 줄어드는 것이 안정입니다.**  그 물리가 부호에 바로
나타납니다.  논문 규약에서는 $\partial q/\partial u > 0$ 이 안정이 되어 어색합니다.

### 3.5 규약에 걸리는 것과 안 걸리는 것

코드를 고치거나 논문 식과 견줄 때 이 표로 대조하십시오.

| 양 | 규약에 걸리나 |
|---|---|
| $\hat J_{ij}$ 의 부호 | **걸린다.**  이 규약에서 음수 |
| $\chi_{ij} = -S_{ij}$ | **걸린다.**  이 규약에서만 양수 |
| $\gamma_i$ | **걸린다.**  $-(\partial q/\partial u)\tilde V_i$ 를 담는다 |
| $\rho_{\mathrm{int}}$ 의 분모 | **걸린다.**  $\mathrm{sym}$ 이 양정치라야 한다 |
| 시간 항 부호 | **걸린다.**  이 규약에서 더한다 |
| $b_{ij}$, $r_{ij}$, $\varepsilon_{ij}$ | 안 걸린다.  절댓값의 비라 부호가 약분된다 |
| $\nu_j$ 와 임계 1 | 안 걸린다.  물성만 보는 값이다 |
| $\Phi_{ii}$ | 안 걸린다.  $\varepsilon$ 의 제곱이 들어간다 |

$$\chi_{ij} > 0 \text{ 은 \textbf{이 규약에서만} 성립합니다}$$

논문 규약이면 음수가 되어 상한 A 와 B 의 전제가 반대로 걸립니다.

## 4. 조립이 하는 일 — 차례대로

### 4.1 간선마다 흐름을 잰다

유한체적법은 노드마다 작은 상자를 두고, 그 상자로 드나드는 흐름을 셉니다.

$$F_{ij} = P_{\text{eff}}\,D_{ij}\,(u_j - u_i)$$

| 기호 | 무엇 |
|---|---|
| $D_{ij}$ | 간선 가중치.  격자가 정한다 |
| $P_{\text{eff}}$ | 두 노드 사이의 유효 확산 계수 |

$$P_{\text{eff}} = \frac{2\,p_i\,p_j}{p_i + p_j}$$

**왜 조화 평균인가.**  두께가 같은 두 물질이 이어져 있을 때, 전체로 흐르는
양은 두 저항을 더한 것으로 정해집니다.  저항은 계수의 역수이므로,
계수 쪽에서 보면 조화 평균이 됩니다.  산술 평균을 쓰면 계수가 몇 자릿수
차이 나는 계면에서 흐름을 크게 부풀립니다.

### 4.2 잔차와 자코비안을 만든다

$$\text{res}_i = -\sum_{j} F_{ij} - q_i \tilde V_i$$

자코비안은 이 잔차를 $u$ 로 미분한 것입니다.  $P_{\text{eff}}$ 가 $u$ 에
의존하므로 비대각 성분이 이렇게 됩니다.

$$\hat J_{ij} = -D_{ij}\Bigl(P_{\text{eff}} + \frac{\partial P_{\text{eff}}}{\partial u_j}\,\delta u\Bigr)$$

$i$ 와 $j$ 를 바꾸면 도함수를 재는 자리가 달라지므로 값이 달라집니다.
**이것이 물리가 만드는 비대칭입니다.**

대각은 이렇게 됩니다.

$$\hat J_{ii} = +\sum_j P_{\text{eff}}D_{ij} \;-\; \frac{\partial q}{\partial u}\tilde V_i$$

$$\text{대각이 양수, 비대각이 음수인 이 꼴을 M-행렬이라 합니다}$$

M-행렬이면 $\mathrm{sym}(\hat J)$ 의 내부 블록이 양정치가 됩니다.
그것이 $\rho_{\mathrm{int}}$ 를 정의할 수 있는 바탕이 됩니다.

> **소스가 스스로를 키우면 대각이 줄어듭니다.**  $\partial q/\partial u > 0$ 이면
> 두 번째 항이 대각을 깎습니다.  그 깎임이 지나치면 양정치를 잃고,
> 그때가 정상해가 없어지는 지점입니다.

### 4.3 Robin 경계를 더한다

$$\alpha\,u + \beta\,\frac{\partial u}{\partial n} = \gamma$$

경계면마다 적분해 잔차와 대각에 더합니다.  `assembleRobinFaces` 가 그 일을
하고, 면으로 안 잡힌 노드는 `assembleRobinNodal` 이 채웁니다.

두 함수를 나눈 까닭은 서로의 값을 안 쓰기 때문입니다.  앞 함수가 「어느
노드를 이미 처리했는지」를 돌려주고, 뒤 함수가 그것을 받아 나머지만 봅니다.

**둘 다 얼마를 더했는지를 따로 돌려줍니다.**  잔차에 더하고 끝내면 그
값이 안 남는데, 보존을 따질 때 「Robin 으로 나간 양」이 따로 있어야
하기 때문입니다.  그것이 `sys.Node.Robin` 으로 담깁니다.

$$(\text{소스가 만든 양}) - (\text{안에 쌓인 양}) = (\text{Dirichlet 로 나간 양}) + (\text{Robin 으로 나간 양})$$

### 4.4 시간 항을 더한다

`InvDt > 0` 이면 대각에 질량을 더합니다.

$$\hat J_{\delta t} = \hat J + \frac{1}{\delta t}\,M, \qquad M = \mathrm{diag}(c_i \tilde V_i)$$

$$\text{res}_{\delta t} = \text{res} + \frac{1}{\delta t}\,c_i\tilde V_i\,(u_i - u_i^{\text{old}})$$

**대각만 건드립니다.**  비대각은 그대로이므로 비대칭의 크기가 안 바뀝니다.
그 성질이 시간 간격을 정하는 근거가 됩니다.  `50_시간전진.md` 참조.

### 4.5 Dirichlet 행을 갈아 끼운다

$u$ 를 못박은 노드에서는 방정식이 필요 없습니다.  그 행의 항목을 전부 빼고,
대각에 값 하나만 넣습니다.

```matlab
phys_scale = max(abs(J_ii));      % 다른 행과 크기를 맞춘다
if phys_scale < 1e-10, phys_scale = 1.0; end
```

**왜 1 이 아니라 다른 행의 크기에 맞추는가.**  대각에 1 을 넣으면 다른 행이
$10^{6}$ 규모일 때 행렬의 조건수가 그만큼 나빠집니다.  크기를 맞추면
Dirichlet 행이 조건수를 안 건드립니다.

이 처리 덕분에 **Dirichlet 행은 값이 0 이 아닌 자리가 정확히 하나**가 됩니다.
그 성질을 두 군데가 씁니다.

| 어디 | 어떻게 쓰나 |
|---|---|
| `dirichletRowsOf` | 행렬 생김새만 보고 Dirichlet 행을 가려낸다 |
| `DirectSolver` | 그 행을 먼저 풀고 나머지를 푼다 |

### 4.6 격자 때문에 생긴 비대칭을 흡수한다

여기서 `AdjointCExtractor` 가 나섭니다.  자세한 것은 4절입니다.

$$\hat C\hat G\hat J = \hat C \cdot \hat G\hat J$$

### 4.7 대칭과 반대칭으로 가른다

$$\tilde A_{\text{int}} = \Pi\,\frac{\hat C\hat G\hat J - (\hat C\hat G\hat J)^{\mathsf T}}{2}\,\Pi$$

$$\tilde J_{\text{pure}} = \hat C\hat G\hat J - \tilde A_{\text{int}}$$

$\Pi$ 는 Dirichlet 자리에 0, 나머지에 1 이 든 대각 행렬입니다.
앞뒤로 곱하면 그 행과 열이 한꺼번에 지워집니다.

경계에서는 비대칭을 따지지 않겠다는 뜻입니다.  거기는 값이 못박혀 있어
풀 것이 없습니다.

> **$\Pi^2 = \Pi$ 입니다.**  0 과 1 만 들었으니 제곱해도 그대로입니다.
> 두 번 걸러도 결과가 안 바뀐다는 뜻이고, 이런 행렬을 사영이라 합니다.

## 5. 격자 때문에 생긴 비대칭을 흡수하는 법 — `AdjointCExtractor`

### 5.1 무엇이 문제인가

같은 간선을 양쪽에서 본 두 성분의 크기가 다릅니다.

$$\frac{\lvert\hat J_{ji}\rvert}{\lvert\hat J_{ij}\rvert} \ne 1$$

이 차이에는 두 가지가 섞여 있습니다.

| 섞인 것 | 흡수할 수 있는가 |
|---|---|
| 노드마다 쌍대 체적 $\tilde V_i$ 가 다르다 | **흡수할 수 있다** |
| $p$ 가 $u$ 에 의존한다 | **남는다.**  이것이 물리 그 자체다 |

### 5.2 어떻게 가르는가

간선마다 두 성분의 비를 로그로 잽니다.

$$y_{ij} = \ln\left\lvert\frac{\hat J_{ji}}{\hat J_{ij}}\right\rvert$$

만약 이 값이 **노드마다 정해진 어떤 수의 차이**로 전부 설명된다면,
그 부분은 노드에 붙은 성질이지 간선의 성질이 아닙니다.  곧 격자 탓입니다.

$$y_{ij} \approx z_j - z_i$$

이런 $z$ 를 찾는 것이 최소제곱 문제가 됩니다.

$$\min_{z}\ \lVert \mathbf E z - y \rVert^2$$

$\mathbf E$ 는 간선마다 한 행을 갖고, 그 행에 $-1$ 과 $+1$ 이 하나씩 든 행렬입니다.
정확히 그래프의 기울기 연산자입니다.

$$\hat c_i = e^{z_i}, \qquad \hat C = \mathrm{diag}(\hat c_i)$$

### 5.3 남는 것을 지우면 안 된다

$$r_{ij} = y_{ij} - (z_j - z_i)$$

이 나머지가 0 이 아니면, 그 비대칭은 노드마다 붙은 수의 차이로 설명되지
않는다는 뜻입니다.  곧 간선 자체가 가진 성질입니다.

**이것을 억지로 지우면 안 됩니다.**

$p$ 가 $u$ 에 따라 달라지기 때문에 생긴 비대칭이고, 그 안에 **해가 어느
쪽으로 가야 하는지**가 들어 있습니다.  온도가 오르면 열전도가 떨어지는
실리콘에서, 뜨거운 쪽과 찬 쪽은 서로 대칭이 아닙니다.  그 방향을 지우면
푸는 문제가 달라집니다.

$$\text{그래서 흡수할 수 있는 만큼만 흡수하고 나머지는 그대로 둡니다}$$

얼마만큼이 흡수됐는지는 이렇게 잽니다.

$$\eta = 1 - \frac{\lVert r\rVert^2}{\lVert y\rVert^2}$$

| $\eta$ | 뜻 |
|---|---|
| 1 에 가깝다 | 비대칭이 거의 격자 탓이었다.  대부분 흡수됐다 |
| 낮다 | 물리가 만든 비대칭이 크다.  $p$ 의 $u$ 의존이 강하다 |

`sys.Eta` 가 이 값입니다.

남은 비대칭은 $\tilde A_{\text{int}}$ 가 되고, 그것이 얼마나 큰지를 재는 것이
$\rho_{\mathrm{int}}$ 입니다.  `60_유도_상한.md` 로 이어집니다.

### 5.4 값 하나를 못박아야 한다

$z$ 에 아무 상수를 더해도 $\mathbf E z$ 가 안 바뀝니다.  차이만 쓰기 때문입니다.
그래서 하나를 정해 주어야 답이 하나로 정해집니다.

| 못박는 것 | 왜 |
|---|---|
| Dirichlet 노드에서 $\hat c = 1$ | 거기는 방정식이 없어 배율이 뜻이 없다 |
| 나머지 노드의 $z$ 평균을 0 | 위와 짝이 맞는 규약이다 |

$\rho_{\mathrm{int}}$ 는 이 선택에 영향을 안 받습니다.  분자와 분모가 같은
배수로 커지기 때문입니다.  다만 조건수와 비대칭 지표는 달라집니다.

### 5.5 같은 격자에서는 분해를 다시 안 한다

$\mathbf E^{\mathsf T}\mathbf E$ 를 분해하는 일이 가장 비쌉니다.  그런데 그 행렬은
**간선 목록에만 의존합니다.**  격자가 그대로면 뉴턴을 몇 번 돌아도 같습니다.

그래서 간선 목록을 열쇠로 삼아 분해 결과를 적어 둡니다.
격자가 바뀌면 열쇠가 달라지므로 다시 만듭니다.

```matlab
s = eng.AdjointCImpl.cacheStats();     % 몇 번 다시 만들었고 몇 번 재사용했는지
```

## 6. Dirichlet 행을 가려내는 두 가지 길

같은 것을 두 방법으로 알 수 있습니다.

| 방법 | 어디서 아는가 |
|---|---|
| `sys.IsDir` | 물성에서.  `U` 를 지정했거나 Robin 의 $\lvert\beta\rvert$ 가 0 이거나 |
| `dirichletRowsOf(A)` | 행렬 생김새에서.  값이 0 아닌 자리가 하나이고 그것이 대각인 행 |

**둘은 같습니다.**  3.5 에서 Dirichlet 행을 그렇게 만들었기 때문입니다.
$N_x = 16,\ 32,\ 64$ 에서 재 보았고 어긋난 노드가 하나도 없었습니다.
내부 노드는 이웃이 넷 이상이라 헷갈릴 일도 없었습니다.

$$\text{그래서 } \texttt{sys.IsDir} \text{ 을 씁니다.  행렬을 다시 훑지 않아도 됩니다}$$

`dirichletRowsOf` 를 남긴 곳은 셋입니다.

| 어디 | 왜 |
|---|---|
| `DirectSolver` | 조립을 거치지 않은 날행렬을 받는다.  `sys` 가 없다 |
| `PROFILE_blocksolve` | 그 함수 자체의 속도를 잰다 |
| `CHECK_B_premise` B.5 | 두 방법이 같은지 대조하는 자리다 |

## 7. 주의할 것

**조립은 `is_Dir` 을 함께 돌려줍니다.**  받아 놓고 `physM.evaluate` 를 다시
불러 같은 것을 또 만들 필요가 없습니다.  같은 좌표에 같은 $u$ 를 넣는 같은
호출이라 결과가 똑같고, 전체 노드의 물성을 헛되이 한 번 더 재게 됩니다.

**`InvDt > 0` 인데 `U_old` 를 안 주면 오류가 납니다.**  조용히 정상 문제를
푸는 것이 되면 안 되므로 일부러 멈춥니다.

**`sys.GJ` 는 부를 때마다 만들어집니다.**  되풀이해 쓸 자리라면 한 번 받아
변수에 담아 두십시오.
