### 1. 이 절의 동기

§6 에서 1-매개변수 부분군이 *항등원의 1차 정보 (생성자 $X$) 로부터 맥클로린 급수 $\sum (tX)^n / n!$ 로 복원* 됨을 보았다. 이 급수가 정확히 *지수 사상* $\exp(tX)$. 본 절에서는 지수 사상을 *그 자체로 본격 분석* 한다.

다룰 것들 —
- *행렬 지수의 정식 정의* 와 수렴성
- *기본 성질* — $\exp(0) = I$, $\exp(-X) = \exp(X)^{-1}$, 미분
- *가환 vs 비가환에서의 지수 법칙* — $\exp(X+Y)$ 의 운명
- *일반 리 군에서의 지수 사상* — 행렬군 너머
- *기하학적 의미* — 항등원 근방의 미분 동형사상
- *왜 지수가 자연스럽게 등장하는가의 깊은 의미* — 미분방정식 유일성
- *지수 사상의 한계 예고* (§12–§14 본격)

이 절로 2부 (1-매개변수 부분군과 준동형) 가 마무리되고, 3부 (리 대수) 로 넘어간다.

### 2. 행렬 지수의 정식 정의

**1)** *정의*. 임의의 $N \times N$ 행렬 $X \in M_N(\mathbb{F})$ ($\mathbb{F} = \mathbb{R}$ 또는 $\mathbb{C}$) 에 대해 *행렬 지수* 는

$$\exp(X) := \sum_{n=0}^{\infty} \frac{X^n}{n!} = I + X + \frac{X^2}{2!} + \frac{X^3}{3!} + \cdots$$

**2)** *수렴*. 위 급수가 *모든 행렬 $X$ 에 대해 절대 수렴*. 노름 비교

$$\left\| \sum_{n=0}^\infty \frac{X^n}{n!} \right\| \le \sum_{n=0}^\infty \frac{\|X\|^n}{n!} = e^{\|X\|} < \infty$$

여기 $\|\cdot\|$ 는 임의의 *서브 곱 행렬 노름* (예 — 작용소 노름, 프로베니우스 노름). $\|XY\| \le \|X\| \|Y\|$ 이라 $\|X^n\| \le \|X\|^n$. 절대 수렴 → 수렴.

**3)** *수렴이 일양함*. 사실 $X$ 가 임의의 *유계 영역* 안에서 움직일 때 위 급수가 *일양 절대 수렴*. 따라서 *항별 미분, 항별 적분* 같은 조작이 자유로움.

**4)** *통상 지수와의 일관성*. $X$ 가 $1 \times 1$ 스칼라이면 $\exp(X)$ 가 통상 $e^X$. 행렬 지수가 *스칼라 지수의 자연스러운 일반화*.

### 3. 행렬 지수의 기본 성질

**1)** *$\exp(0) = I$*. 직접 — $\sum_n 0^n / n! = 1 + 0 + 0 + \cdots = I$ (정의에서 $0^0 = I$).

**2)** *$\exp(-X) = \exp(X)^{-1}$*. $X$ 와 $-X$ 가 가환 ($[X, -X] = 0$) 이라 다음 §4 의 가환 지수 법칙 적용 —

$$\exp(X) \exp(-X) = \exp(X + (-X)) = \exp(0) = I$$

대칭적으로 $\exp(-X) \exp(X) = I$. 따라서 $\exp(X)$ 가 *항상 가역*, 역이 $\exp(-X)$.

> *결과* — $\exp : M_N(\mathbb{F}) \to GL(N, \mathbb{F})$. 임의의 행렬을 *가역 행렬* 로 보낸다. $\det \exp(X) \neq 0$ 자동.

**3)** *$\det \exp(X) = \exp(\text{tr}(X))$*. 행렬 지수의 핵심 항등식 (Jacobi의 공식). 직접 증명 — 대각화 가능 $X$ 에 대해 고유값 $\lambda_i$ 로 $\det \exp(X) = \prod \exp(\lambda_i) = \exp(\sum \lambda_i) = \exp(\text{tr}(X))$. 일반은 연속성 + 대각화 가능 행렬의 조밀성.

이 항등식이 *$\mathfrak{sl}(N)$ 의 정의* ($\text{tr} = 0$) 과 *$SL(N)$ 의 정의* ($\det = 1$) 의 관계를 정확히 매개. §8 본격.

**4)** *$\exp(tX)$ 의 미분*. §6 §5 의 결과 재확인 — 

$$\frac{d}{dt} \exp(tX) = X \exp(tX) = \exp(tX) \, X$$

(항별 미분, $\exp(tX)$ 와 $X$ 의 가환성.)

**5)** *$\exp$ 의 항등원 근방 미분 — $(d \exp)_0$*. 지수 사상의 미분을 $0 \in M_N(\mathbb{F})$ 에서 잡으면

$$(d \exp)_0 : T_0 M_N(\mathbb{F}) = M_N(\mathbb{F}) \to T_I GL(N, \mathbb{F}) = M_N(\mathbb{F})$$

가 *항등 사상*. 즉

$$\left. \frac{d}{dt} \right|_{t=0} \exp(tX) = X = \text{id}(X)$$

이 사실이 다음 §6 의 *항등원 근방 미분 동형사상* 결과의 핵심.

### 4. 가환과 비가환에서의 지수 법칙

행렬 지수의 *덧셈 법칙* $\exp(X + Y) = \exp(X) \exp(Y)$ 가 *언제 성립* 하는지.

**1)** *가환의 경우* $[X, Y] = 0$ *에서*. 성립.

$$\exp(X + Y) = \exp(X) \exp(Y) = \exp(Y) \exp(X)$$

*증명 스케치*. 이항 정리

$$(X + Y)^n = \sum_{k=0}^n \binom{n}{k} X^k Y^{n-k}$$

가 $X, Y$ 가환에서만 성립 (비가환에서는 $XY$ 와 $YX$ 가 섞여 단순한 형태 안 됨). 가환 시

$$\exp(X+Y) = \sum_{n=0}^\infty \frac{(X+Y)^n}{n!} = \sum_{n=0}^\infty \frac{1}{n!} \sum_{k=0}^n \binom{n}{k} X^k Y^{n-k} = \sum_{k, m \ge 0} \frac{X^k Y^m}{k! m!} = \exp(X) \exp(Y)$$

(마지막 등호 — $n = k + m$ 으로 재정렬.)

**2)** *비가환에서는 일반적으로 깨짐*. $[X, Y] \neq 0$ 이면

$$\exp(X + Y) \neq \exp(X) \exp(Y)$$

대신 *BCH 공식* (§0-1 §9) 으로

$$\exp(X) \exp(Y) = \exp\Bigl( X + Y + \frac{1}{2}[X, Y] + \frac{1}{12}([X, [X, Y]] - [Y, [X, Y]]) + \cdots \Bigr)$$

— *교환자 보정 항* 이 따라붙는다.

**3)** *비가환 반례 — 파울리 행렬*. $X = i \sigma_x$, $Y = i \sigma_y$ (반에르미트, $\mathfrak{su}(2)$ 원소). $[X, Y] = [i\sigma_x, i\sigma_y] = -[\sigma_x, \sigma_y] = -2i\sigma_z \neq 0$ (§3 §5).

직접 계산하면

$$\exp(X) = \exp(i\sigma_x) = \cos(1) I + i \sin(1) \sigma_x$$

(왜냐하면 $\sigma_x^2 = I$, 따라서 $\exp(i\sigma_x) = \sum (i\sigma_x)^n / n! = \cos(1) I + i \sin(1) \sigma_x$ — 오일러 공식의 행렬 버전.)

비슷하게 $\exp(Y) = \cos(1) I + i \sin(1) \sigma_y$. 

곱하면 $\exp(X) \exp(Y)$ 는 $I, \sigma_x, \sigma_y, \sigma_x \sigma_y = i \sigma_z$ 의 결합. 반면 $\exp(X + Y)$ 는 $X + Y = i(\sigma_x + \sigma_y)$ 의 지수로, $(\sigma_x + \sigma_y)^2 = \sigma_x^2 + \sigma_x \sigma_y + \sigma_y \sigma_x + \sigma_y^2 = 2I$ (왜냐하면 $\sigma_x \sigma_y + \sigma_y \sigma_x = 0$, anticommutator $= 0$ 인 파울리 행렬 성질) 이라 다른 형태.

→ $\exp(X+Y) \neq \exp(X) \exp(Y)$.

**4)** *결론*. 지수 법칙 $\exp(X+Y) = \exp(X) \exp(Y)$ 는 *$X, Y$ 의 가환성* 과 정확히 동치. 가환은 *예외*, 비가환은 *일반*. BCH 보정이 비가환을 처리.

### 5. 일반 리 군에서의 지수 사상

행렬군에서 지수 사상은 *행렬 지수* 로 명시적. 일반 리 군에서는 어떻게 정의되나.

**1)** *1-매개변수 부분군의 존재·유일성 정리*. 일반 리 군 $G$ 와 임의 $X \in T_e G = \mathfrak{g}$ 에 대해, *$X$ 를 생성자로 가지는 1-매개변수 부분군이 유일하게 존재*

$$\gamma_X : \mathbb{R} \to G, \quad \gamma_X(0) = e, \quad \gamma_X'(0) = X, \quad \gamma_X(s+t) = \gamma_X(s) \gamma_X(t)$$

증명 — 매끄러운 다양체 위의 *왼쪽 불변 벡터장* 의 흐름 (flow) 으로 구성. 미분 위상수학의 ODE 존재·유일성 정리 + 군 구조 활용.

**2)** *지수 사상의 일반 정의*.

$$\exp : \mathfrak{g} \to G, \qquad \exp(X) := \gamma_X(1)$$

— *$X$ 가 생성하는 1-매개변수 부분군의 $t = 1$ 위치*.

**3)** *일관성*. 행렬군 $G \subseteq GL(N, \mathbb{F})$ 의 경우, 1-매개변수 부분군이 $\gamma_X(t) = \exp(tX)$ (§6 §7), 따라서 $\gamma_X(1) = \exp(X)$ — *행렬 지수와 일치*. 일반 정의가 행렬군 정의의 자연스러운 확장.

**4)** *기본 성질 — 일반 리 군에서도 성립*.
- $\exp(0) = e$
- $\exp(-X) = \exp(X)^{-1}$
- $\exp((s+t)X) = \exp(sX) \exp(tX)$ (가환 — $X, X$ 자신과 가환)
- $\exp(X) \exp(Y) = \exp(X+Y)$ 는 $[X, Y] = 0$ 일 때만

**5)** *왜 $t = 1$ 인가*. *스칼라 $t$ 를 $X$ 안에 흡수* 하면 $\exp(tX) = \exp(t \cdot X) = \gamma_X(t) = \gamma_{tX}(1)$. 즉 $\exp(tX)$ 도 $\exp$ 의 결과 ($tX \in \mathfrak{g}$ 의 지수). 따라서 $t = 1$ 만 명시해도 모든 $t$ 의 결과를 얻는다.

### 6. 지수 사상의 기하학적 의미

$\exp : \mathfrak{g} \to G$ 의 기하학적 그림.

**1)** *시작점 — 0과 항등원*. $\exp$ 가 *$\mathfrak{g}$ 의 영벡터 $0$ 을 $G$ 의 항등원 $e$ 로* 보낸다.

$$\exp(0) = e$$

**2)** *$\exp$ 의 미분 $(d\exp)_0$ 가 항등*. §3 (5) 의 결과. 

$$(d \exp)_0 : T_0 \mathfrak{g} = \mathfrak{g} \to T_e G = \mathfrak{g}$$

가 *항등 사상*.

(첫 등호는 벡터 공간 $\mathfrak{g}$ 의 한 점에서의 접공간이 자기 자신, 두 번째 등호는 §0-4 §10.)

**3)** *역함수 정리 — 항등원 근방의 미분 동형사상*. $(d\exp)_0 = \text{id}$ 가 *가역 선형 사상* 이라, 역함수 정리에 의해

> $\exp$ 가 $\mathfrak{g}$ 의 $0$ 근방에서 $G$ 의 $e$ 근방으로의 *미분 동형사상 (diffeomorphism)*.

즉 *항등원 근방* 에서는 $\exp$ 가 *완벽한 일대일 대응* (역사상 $\log$ 존재, 매끄러움 양방향).

**4)** *항등원 근방에서 $\log$ 사상*. $\log : (\text{$e$ 근방}) \to (\text{$0$ 근방})$ 이 $\exp$ 의 역. 행렬군에서는 $\log(I + Y) = Y - Y^2/2 + Y^3/3 - \cdots$ (작은 $Y$ 에 수렴).

**5)** *전역적 미분 동형사상이 아님*. *항등원 근방에서만 보장*. 전역적으로는 (a) 단사 안 됨 (예 — $\exp(2\pi i n) = 1$, 주기), (b) 전사 안 됨 (비컴팩트 등에서, §13). 이 한계가 §12–§14 의 주제.

**6)** *시각적 그림*. $\mathfrak{g}$ (평평한 벡터 공간) 에서 $G$ (휘어 있을 수 있는 다양체) 로의 *항등원 근방 평탄화*.

> 비유 — 지구 표면 위 한 점에서 *접평면* 으로 사영하면 가까운 곳은 일대일이지만 멀어지면 깨진다 ($\exp$ 의 역할). 리 대수는 *항등원의 접평면*, 리 군은 *전체 표면*.

### 7. 왜 지수 함수가 등장하는가 — 깊은 의미 (미분방정식 유일성)

§6 의 도출 ($\sum (tX)^n/n!$ 이 자연 등장) 은 *왜 지수* 인지에 대한 답이지만, 그 *깊은 의미* 가 *미분방정식 유일성* 에 있다.

**1)** *통상 지수 함수의 유일성*. 통상 지수 함수 $y(t) = e^{at}$ 는

$$y'(t) = a \, y(t), \qquad y(0) = 1$$

의 *유일한 매끄러운 해*. 다른 어떤 함수도 이 두 조건을 동시에 만족 못 함. 이것이 *지수 함수가 자연 등장* 하는 표준 설명.

**2)** *행렬 지수의 유일성*. 마찬가지로 행렬 지수 $\gamma(t) = \exp(tX)$ 는

$$\gamma'(t) = X \, \gamma(t), \qquad \gamma(0) = I$$

의 *유일한 매끄러운 해* (ODE 의 존재·유일성 정리, *Picard-Lindelöf*).

§6 §5 에서 *합성 법칙이 이 미분방정식을 강제* 함을 보았다. 따라서 *합성 법칙을 만족하는 매끄러운 1-매개변수 곡선이 항등원에서 출발할 때, 그 곡선이 유일하게 지수 함수*. *다른 선택지가 없음*.

**3)** *통상 지수와의 평행성*.

| 통상 지수 | 행렬 지수 / 리 군 지수 사상 |
|---|---|
| $e^{at}$ | $\exp(tX) = \gamma_X(t)$ |
| 매개변수 — 스칼라 $a$ | 매개변수 — 리 대수 원소 $X$ |
| ODE: $y' = ay, y(0) = 1$ | ODE: $\gamma' = X\gamma, \gamma(0) = e$ |
| 합성: $e^{a(s+t)} = e^{as} e^{at}$ | 합성: $\exp((s+t)X) = \exp(sX) \exp(tX)$ |
| 유일 해 = 지수 | 유일 해 = 지수 사상 |

**4)** *깊은 결론*. *지수 함수의 유일성이 합성 법칙에서 강제* 되는 것이 *왜 지수가 자연스럽게 등장하는가* 의 가장 깊은 답. 합성 법칙 + 매끄러움이면 *어떤 군 위에서 든 (가환·비가환 무관)* 지수가 유일한 해.

리 군의 *모든 1-매개변수 부분군이 지수 형태* 인 것이 *공허한 약속* 이 아니라 *합성 법칙의 수학적 필연*.

### 8. 행렬 지수의 구체 계산 — 스펙트럼 분해

행렬 지수를 명시적으로 계산하는 방법. §0-5 §9 의 함수 계산 결과 활용.

**1)** *대각화 가능 $X$ 의 경우*. $X = \sum_i \lambda_i |\lambda_i\rangle \langle \lambda^i|$ 의 스펙트럼 분해 (§0-5 §8). 행렬 지수는

$$\exp(X) = \sum_i e^{\lambda_i} \, |\lambda_i\rangle \langle \lambda^i|$$

— *고유값에 지수를 씌우고 고유벡터 구조는 그대로*. 

매개변수 $t$ 포함 시 

$$\exp(tX) = \sum_i e^{t \lambda_i} \, |\lambda_i\rangle \langle \lambda^i|$$

**2)** *해석 — 각 고유 모드의 독립 진화*. $X$ 의 고유 모드 $|\lambda_i\rangle$ 가 *서로 독립적으로 $e^{t\lambda_i}$ 배율* 로 진화.
- $\lambda_i$ 실수 — *지수 증가/감소*
- $\lambda_i$ 순허수 — *조화 진동* (반에르미트, 유니타리 진화)
- $\lambda_i$ 복소 — 증가/감소 + 진동 (자기에너지)

**3)** *반에르미트 행렬의 경우* (리 대수의 표본). $X \in \mathfrak{u}(N)$ 또는 $\mathfrak{su}(N)$ 이라 $X^\dagger = -X$. 고유값 $\lambda_i$ 가 *순허수*. $\exp(X)$ 가 *유니타리* — 모듈러스 1 고유값 ($|e^{\lambda_i}| = 1$).

→ $\exp : \mathfrak{u}(N) \to U(N)$. 반에르미트 → 유니타리.

**4)** *에르미트 행렬의 경우*. $X = X^\dagger$ 이라 $\lambda_i$ 실수. $\exp(X)$ 가 *양의 정부호 에르미트 행렬*. $\exp : \text{Herm}(N) \to \text{Pos}(N)$.

(에르미트는 $i\mathfrak{u}(N)$ 과 대응. 물리에서 해밀토니안 = $i\hbar$ × 시간 진화 생성자, 둘이 ($i$ 배 차이로) 연결.)

**5)** *비대각화 가능 (조던 형) $X$*. 위 식 변형 — 일반화된 고유벡터 사용. 본 시리즈에서는 대각화 가능 경우만 다룬다.

### 9. 구체 예시들

**1)** *$(\mathbb{R}, +)$ — 가장 단순*. $\mathfrak{g} = \mathbb{R}$, $G = \mathbb{R}$ (덧셈군). $\exp : \mathbb{R} \to \mathbb{R}$ 이 *항등 사상* $\exp(X) = X$ (덧셈군 자체로의 지수는 자명).

*주의* — 다른 견해 — $G = (\mathbb{R}^+, \cdot)$ 으로 보면 $\exp : \mathbb{R} \to \mathbb{R}^+$, $X \mapsto e^X$. 통상 지수. 두 견해 모두 *같은 가환 1-차원 리 군* 의 다른 표현 (§1 §6).

**2)** *$SO(2)$ 또는 $U(1)$* (§6 §10 재확인). $\mathfrak{so}(2) = \mathbb{R} \cdot J$ ($J = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$).

$$\exp(\theta J) = R(\theta) = \begin{pmatrix} \cos \theta & -\sin \theta \\ \sin \theta & \cos \theta \end{pmatrix}$$

$U(1)$ 표현으로는 $\mathfrak{u}(1) = i\mathbb{R}$, $\exp(i\theta) = e^{i\theta} \in U(1)$. *오일러 공식*.

**3)** *$SU(2)$* (§16 본격 예고). $\mathfrak{su}(2) = i \cdot (\text{실 선형 결합 of $\sigma_x, \sigma_y, \sigma_z$})$. 예 — $X = i \theta \sigma_z$.

$\sigma_z^2 = I$ 이라 ($\sigma_z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$, $\sigma_z^2 = I$) 

$$\exp(i \theta \sigma_z) = \cos\theta \, I + i \sin\theta \, \sigma_z = \begin{pmatrix} e^{i\theta} & 0 \\ 0 & e^{-i\theta} \end{pmatrix}$$

— 일반 파울리 방향에 대한 지수가 *Rodrigues 공식의 SU(2) 버전*. §16.

**4)** *$SO(3)$* — 회전 (§17 본격 예고). $\mathfrak{so}(3) = $ 반대칭 $3\times 3$ 실 행렬 = $\mathbb{R}^3$ (단위 벡터 → 반대칭 행렬). 예 — $\hat n \in S^2$ 단위 벡터 + 각도 $\theta$ 에 대해 회전축 $\hat n$, 각도 $\theta$ 회전 = $\exp(\theta \, A_{\hat n})$ where $A_{\hat n}$ 은 $\hat n$ 에 대응하는 반대칭 행렬. *Rodrigues 회전 공식*.

### 10. 지수 사상의 한계 — 예고

지수 사상이 *완벽한 다리* 는 아니다. 다음 §12–§14 에서 본격 다룰 한계.

**1)** *단사가 아님 (일반적으로)*. 예 — $\exp : \mathbb{R} \to U(1)$, $\theta \mapsto e^{i\theta}$ — *$2\pi$ 주기*. 다른 $\theta$ 가 같은 결과. 일반 가환 컴팩트 ($T^N$) 에서도 격자 주기성.

**2)** *전사가 아님 (비컴팩트에서)*. 예 — $SL(2, \mathbb{R})$ 의 $\begin{pmatrix} -1 & 1 \\ 0 & -1 \end{pmatrix}$ 같은 원소가 $\exp$ 의 이미지에 없음 (§2 §5 (1)). 일반 비컴팩트 리 군에서 지수가 전사 안 될 수 있다 — *지수의 곱 필요* (§13).

**3)** *비연결 경우*. $O(N) = SO(N) \cup (-I) \cdot SO(N)$ 같은 비연결 리 군에서, 지수는 *항등원 성분* 에만 도달. *비연결 부분* 은 *이산 변환과의 곱* 으로만 도달 (§14).

**4)** *컴팩트 연결의 경우*. *지수가 전사*. 모든 원소가 단일 $\exp(X)$. 가장 깔끔한 경우 (§12).

**5)** *세 가지 한계의 위계*.
- 컴팩트 + 연결 — 전사 OK, 단사는 가환 부분에서 깨질 수 있음 (정규화로 해결)
- 비컴팩트 — 전사 깨짐, 지수의 곱 필요
- 비연결 — 항등원 성분만 도달, 이산 변환 추가 필요

### 11. 이 절을 닫으며 + 2부 정리

이 절에서 점검한 것.

(1) *행렬 지수의 정식 정의* — $\exp(X) = \sum_n X^n / n!$. 항상 절대 수렴.

(2) *기본 성질* — $\exp(0) = I$, $\exp(-X) = \exp(X)^{-1}$, $\det\exp = \exp\text{tr}$, $\exp$ 가 항상 가역으로 보냄.

(3) *가환·비가환 지수 법칙* — $\exp(X+Y) = \exp(X)\exp(Y)$ ↔ $[X, Y] = 0$. 비가환은 BCH 보정.

(4) *일반 리 군의 지수 사상* — $\exp : \mathfrak{g} \to G$, $X \mapsto \gamma_X(1)$. 행렬군의 행렬 지수와 일관.

(5) *기하학적 의미* — $(d\exp)_0 = \text{id}$, 항등원 근방의 미분 동형사상. 전역적이 아닌 *국소적 1:1*.

(6) *왜 지수인가의 깊은 의미* — 미분방정식 $\gamma' = X\gamma, \gamma(0) = e$ 의 *유일한 해* 가 지수. 합성 법칙이 이 ODE 를 강제, 따라서 *지수가 자연스럽게 등장* 하는 것이 *수학적 필연*.

(7) *스펙트럼 분해* — $\exp(tX) = \sum_i e^{t\lambda_i} |\lambda_i\rangle \langle \lambda^i|$. 고유값에 지수, 고유벡터 구조 유지.

(8) *한계 예고* — 단사·전사·연결성 모두 깨질 수 있음. §12–§14 본격.
